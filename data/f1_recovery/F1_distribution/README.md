## 파일 위치

`all_years/`의 CSV 6개가 작업 대상입니다. 원래 파일 이름, 컬럼 순서, UTF-8 인코딩을 유지했습니다. 문서는 `docs/데이터_명세서.html`, `docs/프로젝트_시나리오.html`을 브라우저로 열면 됩니다. 같은 내용의 Markdown도 함께 제공합니다.

## 읽을 때 주의할 점

날짜·ID·소수점·빈칸을 임의 변환하지 말고 우선 문자열로 읽으십시오. 빈 문자열과 0은 같은 값이 아닙니다. 원본 수집 단계의 결측이나 경기 특성에 따른 예외도 존재할 수 있으므로, 특이해 보인다는 이유만으로 일괄 변경하지 마십시오.

```python
import pandas as pd
laps = pd.read_csv("all_years/laps.csv", dtype=str, keep_default_na=False)
```
