# F1 데이터 명세서 (원천 11종)

기준: `F1_P2_Spec.md` 2장(수집 범위)·5장(Silver)·7장(포인트)·11장(체크리스트), 표준사전 `data/02_reference/standard_dictionary/`.

- 대상 기간: 2023년~2026-10-14 실제 완료된 Race 세션 87개. Qualifying은 `starting_grid` 연결용으로만 쓰고, Sprint는 수집·포인트 범위에서 제외한다.
- 원천: 기존 오염 6종(`data/01_raw/F1_distribution.zip` → 파이프라인 정제 결과 `data/03_cleaned/repaired/`) + 미오염 신규 5종(`data/01_raw/f1_extra_data/`, zip 해제).
- 모든 값은 문자열로 보존하고, 검증·적재 시 형식을 확인한 뒤에만 숫자·일시로 변환한다. 변환 실패나 결측을 0으로 바꾸지 않는다.
- 일시는 모두 UTC(+00:00). 기존 6종은 `2023-03-05 14:01:02.943000+00:00`, 신규 5종은 `2023-03-05T14:01:02.943000+00:00` 형식이다.
- 공백 건수는 정제 후 기준(2026-10-15 실행). 컬럼 정의는 `column_dictionary.csv`와 같다.

## 2. 관계

```text
sessions (session_key, meeting_key)
 ├─ drivers (session_key, driver_number) ── laps / stints / pit / session_result / position / intervals
 │                                        └─ race_control (driver_number 있을 때만)
 ├─ weather (session_key, date)
 └─ meeting_key ── starting_grid (Qualifying session_key)  ※ session_key 직접 JOIN 금지
```

- `starting_grid` → Race: `starting_grid.meeting_key = sessions.meeting_key AND sessions.session_type = 'Race'` 로 Race `session_key`를 찾고 `driver_number`로 결과에 연결한다.
- 랩 ↔ 스틴트는 `lap_start ≤ lap_number ≤ lap_end` 범위 JOIN, 랩·피트 ↔ 기상·순위·격차는 시각 기준 as-of JOIN이다. JOIN 전후 행 수를 비교해 증폭을 막는다(VC70·VC71).
- 드라이버는 세션별 `driver_number`로만 식별하고, 경기 당시 소속팀(`drivers.team_name`)으로 포인트를 귀속한다.

## 3. 본경기 기본 포인트

`race_points_rules.csv`: 1~10위 25-18-15-12-10-8-6-4-2-1, 11위 이하·미분류 0점. 2023~2024 최속 랩 보너스와 Sprint는 제외한다. 결과 컬럼명은 `race_base_points`, `cumulative_race_base_points`, `race_base_points_team_rank`로 공식 챔피언십 점수와 구분한다.

원천 `session_result.points`와 비교하면 47행이 다르다: 최속 랩 보너스 +1 37행, 원천 누락(예: 2023 Jeddah 2위 0점, 2023 Austin 2~10위 0점) 10행. 재계산값의 Race별 합계는 87경기 모두 101점이고, 드라이버 합계와 팀 합계는 시즌별로 일치한다(2023 2,222 · 2024 2,424 · 2025 2,424 · 2026 1,717).
