공식 챔피언십 전체 점수 아님

빠르기만으로 실제 성적을 설명할 수 있을까요? 획득한 포인트와 가까운 팀까지의 격차를 보며 영입 검토의 배경을 이해하는 부분입니다.

Sprint·패스티스트 랩 보너스와 예외 배점·사후 정정은 이 재구성 값에 포함하지 않습니다. 미확정 결과는 0점으로 바꾸지 않습니다.

03 / CANDIDATE EXPLORER

영입 후보 비교

지표와 표시를 처음 읽는다면

전체 페이스·동료 대비·일관성·타이어 추세는 낮을수록, 포인트는 높을수록 좋은 관측값입니다. 일관성은 조건 보정 IQR(페이스 편차), 타이어 유지는 필드 대비 변화 추세이며 순수 마모 능력은 아닙니다. 1ms는 0.001초입니다.

팀 동료 대비는 각자 자신의 동료와 비교한 값입니다. 후보와 기준 선수가 같은 차를 타고 직접 대결한 결과가 아닙니다. 카드별 수치는 각자의 표본이며 공통 경기 비교와 순서가 다를 수 있습니다.

‘1차 검토’는 기본 조건에서 페이스와 본인 동료 대비 값이 기준에 맞았다는 뜻입니다. 함께 표시한 안정성 판정은 11조건·재표집·전후반 검증의 결과입니다. 둘은 구분해서 보세요.

정렬은 한 지표의 관측값 순서입니다. 계약·급여·이적 가능성은 검토하지 않았으며, 후보의 기존 차에서 얻은 성적을 영입 후 효과로 해석할 수 없습니다.

색은 같은 열 안에서만 비교하세요. 피트레인 시간에는 이동시간이 포함되며 순수 정지시간과 다릅니다. 시간·정지시간의 차이는 같은 경기의 타 팀 기준 대비 값이며 음수는 짧은 방향입니다. 시간 값은 경기별 중앙값을 다시 중앙값으로 모은 값이며, 원시간은 서킷 구성의 영향도 받습니다. 긴 이벤트에는 혼잡·정비·경기 상황이 섞일 수 있어 크루나 선수 실력으로 바로 해석하지 않습니다. 피트 횟수와 스틴트 길이도 전략의 우열을 뜻하지 않습니다.

아래 항목은 서로 겹칠 수 있으므로 더해서 오염률로 해석하지 않습니다. 해결되지 않은 연결값은 해당 성능 비교에서 제외하거나 판단 보류하며, 원천 파일을 임의로 채우지 않습니다.

판단할 때 꼭 알아둘 한계
  • 서로 다른 차량에서 얻은 상대 페이스는 선수 효과와 차량 효과를 분리하지 못합니다. 조건별 우위가 반복되어도 이적 효과가 입증되는 것은 아닙니다.
  • 타이어 지표는 필드 대비 페이스 변화 추세입니다. 물리적 마모량이나 순수한 타이어 관리 능력과 같지 않습니다. 일관성 지표도 사고 확률이 아닙니다.
  • 본경기 기본 포인트는 공식 전체 챔피언십 점수가 아닙니다. 배분금·스폰서 수익 증가액은 계산하지 않으며, 성적과 경제적 기회의 관계만 정성적으로 설명합니다.
  • 소속은 각 선수의 해당 시즌 마지막 관측 구간을 선택합니다. 현재 활동 명단·계약 명단이 아닙니다. 이적 전 기록을 새 팀에 합치지 않으며 팀명 변경도 자동 통합하지 않습니다.
  • 전체 87경기의 원천 결과를 독립적인 공식 기록으로 전수 대조한 것은 아닙니다. 수집 당시 HTTP 상태·시각·원문 JSON이 남아 있지 않은 항목은 복원하지 않았습니다.
정제 기준 · 비교 단위 · 안정성 판정 읽는 법
  • 필드 상대 페이스: 같은 경기·컴파운드·5랩 구간의 타 선수 4명·타 팀 3개 이상을 기준으로 산출합니다. 경기별 값을 먼저 만든 뒤 시즌 중앙값을 사용합니다.
  • 기본 필터: 건조 타이어·강수 0·날씨 90초 이내 연결, 피트 전후 랩과 SC/VSC·황기·적기·재시작 구간 제외. 타이어 구간이 모호하거나 연결되지 않는 랩은 성능 비교에서 제외합니다.
  • 프로필: 8경기·200개 참조 연결 랩 이상. 동료 비교: 같은 경기·랩·타이어, 타이어 나이 차이 3랩 이내, 시작 시각 차이 90초 이내, 경기당 8쌍·시즌 5경기 이상.
  • 후보 비교: 같은 경기의 필드 상대 페이스 차이 중앙값(후보 − 기준 선수, %p). 공통 8경기 이상이며, 엄격한 표본 조건은 10경기 이상입니다. 경기 단위 2,000회 재표집으로 기술적 95% 구간을 만듭니다.
  • “페이스 우위 반복”: 11조건 모두 유효·음수, 기본 95% 구간이 0 아래, 시즌 일정의 전·후반 각각 4경기 이상에서 음수. “동료 비교까지 반복”: 여기에 후보의 동료 대비 11조건 음수 및 동료 차이의 기본 95% 구간도 0 아래.
  • 타이어·IQR 후보 차이는 기본 조건의 보조 지표입니다. 타이어는 같은 경기·컴파운드를 맞추고 4경기 이상, IQR은 공통 8경기 이상입니다. 11조건에서 타이어·IQR까지 검증했다는 의미가 아닙니다.
  • 조건별 민감도와 재표집 구간은 관측 자료의 내부 점검입니다. 다중 비교 보정이나 독립된 미래 데이터로 일반화 성능을 검증한 결과는 아닙니다. N/A는 동률·실패·0을 뜻하지 않습니다.
