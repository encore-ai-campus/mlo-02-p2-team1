# 데이터 사전

[README.md](../README.md)의 「데이터 사전」 상세입니다. 서로 다른 파일에서 같은 의미의 데이터를 같은 이름·타입·단위·코드·검증 규칙으로 해석하기 위한 기준이며, 원본은 [data/02_reference/standard_dictionary](../data/02_reference/standard_dictionary/README.md)에 있습니다. 통합본은 [표준사전 PDF](../data/02_reference/standard_dictionary/F1_AI_data_standard_dictionary.pdf)입니다.

## 1. 구성

| 구성 | 파일 | 정의 내용 |
|---|---|---|
| 표준단어 | [standard_words.csv](../data/02_reference/standard_dictionary/standard_words.csv) | 업무 개념을 구성하는 단어와 의미 |
| 표준용어 | [standard_terms.csv](../data/02_reference/standard_dictionary/standard_terms.csv) | 단어 조합으로 만든 용어와 식별자 규칙 |
| 도메인 | [domains.csv](../data/02_reference/standard_dictionary/domains.csv) | 타입·길이·단위·결측 허용·값 범위 |
| 코드 | [codes.csv](../data/02_reference/standard_dictionary/codes.csv) | 허용 코드와 코드별 의미 |
| 컬럼사전 | [column_dictionary.csv](../data/02_reference/standard_dictionary/column_dictionary.csv) | 원천 11종의 파일·컬럼별 표준용어, 도메인, 검증 규칙 |
| 진단 기준 | [diagnostic_codes.csv](../data/02_reference/standard_dictionary/diagnostic_codes.csv) | 오염 유형·심각도·탐지 조건·기본 조치 (DQ001~DQ027) |

컬럼 정의를 원천별로 읽기 쉽게 정리한 문서는 [11종 데이터 명세서](../data/02_reference/schema/F1_데이터_명세서.md)이고, DB 설계는 [TO-BE 모델](../data/02_reference/schema/TO_BE_model_design.md)입니다.

## 2. 주요 적용 기준

- 컬럼명은 `snake_case`, 식별자는 `_key`, 순번은 `_number`, 소요시간은 `_duration`으로 구분합니다.
- 세션 연결은 `session_key`, 드라이버 연결은 `session_key + driver_number`를 사용합니다. `meeting_key`와 `session_key`는 다른 개념입니다.
- 원본 값은 문자열로 보존하고 계산·검사할 때만 숫자·일시로 해석합니다. 빈 문자열을 임의로 0으로 바꾸지 않습니다.
- 시간 길이는 초, 기온·노면온도는 섭씨로 정의합니다. 날짜시간은 UTC 오프셋을 포함해 해석합니다.
- 타이어 코드는 `SOFT`, `MEDIUM`, `HARD`, `INTERMEDIATE`, `WET`, `UNKNOWN`으로 관리합니다. `UNKNOWN` 부여는 실제 종류 복원을 의미하지 않습니다.
- 드라이버 국가 코드와 개최국 코드를 구분하고, `segments_sector_1~3`은 목록 형태의 원문을 보존합니다.
- 격차는 숫자와 `+N LAP(S)` 표현을 구분하며, 예선 `starting_grid`와 Race 결과는 세션 매핑 후 연결합니다.
- `lane_duration`과 `stop_duration`을 분리해 피트레인 체류시간과 정지시간을 혼동하지 않습니다.
- 포인트는 공식 챔피언십 점수와 구분해 `race_base_points`(1~10위 25-18-15-12-10-8-6-4-2-1, 최속 랩 보너스·Sprint 제외)로 부릅니다.
