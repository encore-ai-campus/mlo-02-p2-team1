# 드라이버를 바꾸면 우승확률이 얼마나 달라지나

[README.md](../README.md)의 「③-2 교체하면 우승확률은?」 상세입니다. 질문은 **"현재 데이터를 근거로 다른 드라이버를 우리 자리에 앉히면 우승확률을 볼 수 있을까?"**입니다. 사례는 발표와 같은 **2025 Aston Martin · Lance STROLL 자리**입니다.

## 결론

- **볼 수 있다. 다만 우승확률은 차량이 거의 정한다.** 지금 라인업의 시즌 1승 이상 확률은 0.1%입니다. 2025 Aston Martin 차량으로는 후보 대부분이 1~3%에 머뭅니다.
- **우승이 현실적인 후보는 VERSTAPPEN 한 명입니다.** 시즌 1승 이상 확률은 64%(2025만 쓰면 40%)입니다. 다만 VERSTAPPEN은 다른 팀 선수와 직접 비교할 근거가 없는 연결 그룹에 있어 과대평가됐을 수 있습니다(아래 「한계」 참고).
- **현실적인 목표는 우승보다 팀 순위 6위입니다.** LECLERC로 바꾸면 팀 기대 포인트가 65점에서 108점이 되고, 팀 6위 이내 확률이 9%에서 65%로 오릅니다. 포디움 1회 이상 확률도 9%에서 49%가 됩니다.
- **발표의 1순위 RUSSELL은 추정 방식에 따라 결과가 달라집니다.** 2025만 쓰면 기대 포인트가 +25점이지만, 2023~2025를 쓰면 HAMILTON과 비교되면서 효과가 거의 사라집니다(+4점). 발표의 "차량 효과를 분리하지 않았다"는 한계가 여기서 숫자로 드러납니다.

## 방법

[pipeline/driver_swap.py](../pipeline/driver_swap.py)가 정제 결과(`data/03_cleaned`)와 `session_result`만으로 계산합니다.

| 단계 | 내용 |
|---|---|
| ① 경기별 레이스 페이스 | 본경기에서 1랩·피트 인/아웃 랩·격리 행과 그 경기 정상 랩 중앙값의 107%를 넘는 랩(SC·VSC 등)을 뺍니다. 정상 랩이 5개 이상인 드라이버의 랩타임 중앙값이 경기 전체보다 몇 % 느린지 계산합니다. |
| ② 차량·선수 효과 분리 | 페이스를 "경기별 팀 차량 효과 + 선수 효과"로 나눕니다. 2023~2025를 함께 넣어 팀을 옮긴 선수(SAINZ, HAMILTON 등)가 팀 사이를 잇게 하고, 경기 수가 적은 선수는 0 쪽으로 줄입니다. |
| ③ 시즌 재현 | 2025 본경기 24경기를 "그 경기 차량 효과 + 선수 효과 + 당일 변동"으로 경기마다 4,000번 다시 치릅니다. 완주 실패는 팀별 2025 비완주율로 뽑고, 포인트는 본경기 기본 배점을 씁니다. |
| ④ 교체 | 기준 선수와 후보가 자리를 맞바꿉니다. 후보는 Aston Martin 차량에, STROLL은 후보 팀 차량에 앉고 나머지는 그대로입니다. |

당일 변동 σ는 실제 라인업으로 재현했을 때 실제 우승자를 가장 잘 맞히는 값(0.35%)으로 정했습니다.

## 모델이 실제 결과를 얼마나 맞히나

실제 2025 라인업을 그대로 넣고 재현한 결과입니다. 출처: [calibration.csv](../data/05_gold/driver_swap/calibration.csv), [calibration_team_points.csv](../data/05_gold/driver_swap/calibration_team_points.csv).

| 지표 | 값 |
|---|---:|
| 팀별 기대 포인트와 실제 기본 포인트의 상관 | 0.99 |
| 팀별 포인트 평균 절대 오차 | 20.6점 |
| 경기별 예상 순위와 실제 순위의 스피어만 상관(평균) | 0.78 |
| 우승 확률 1위 선수가 실제 우승한 비율 | 37.5% (24경기 중 9경기) |

팀 단위 시즌 결과는 잘 맞지만, 경기 하나의 우승자를 맞히는 힘은 약합니다. 그래서 결과는 **경기 하나보다 시즌 합계(기대 포인트, 팀 순위)**로 읽는 것이 맞습니다.

## 한계

- **비교 연결 그룹:** 같은 경기·같은 팀으로 함께 달린 선수끼리만 차이가 데이터로 이어집니다. 2023~2025에서 Aston Martin(ALONSO·STROLL)과 McLaren(NORRIS·PIASTRI)은 다른 팀과 연결되지 않습니다. Red Bull 계열(VERSTAPPEN·TSUNODA·LAWSON·HADJAR)도 따로 묶입니다. 그룹이 다르면 "각 그룹 평균이 전체 평균과 같다"는 가정으로만 비교되므로, **STROLL과 모든 후보의 비교에 이 가정이 들어 있습니다.**
- 차량 효과는 그 경기에서 관측된 팀 평균입니다. 선수가 바뀌면 달라질 차량 개발·전략·셋업은 넣지 않았습니다.
- 출발 순위, 추월 난이도, 전략, 세이프티카는 따로 모델링하지 않고 당일 변동 하나에 담았습니다.
- 비완주는 팀(차량) 비완주율로 뽑습니다. 선수 실수로 인한 리타이어 차이는 반영하지 않습니다.
- 확률은 "이 가정이 맞다면"의 값입니다. 영입 후 실제 성적이나 계약 가능성을 말하지 않습니다.

## 실행

```powershell
python -m pipeline.driver_swap                                         # 2025 Aston Martin STROLL 자리, 2023~2025로 선수 효과 추정
python -m pipeline.driver_swap --window 1 --out data/05_gold/driver_swap_2025only   # 2025만으로 추정(민감도)
python -m pipeline.driver_swap --year 2024 --team Ferrari --driver "Carlos SAINZ"   # 다른 팀·시즌
```

출력은 `data/05_gold/driver_swap/`에 생성됩니다: `scenarios.csv`, `race_detail.csv`, `calibration.csv`, `calibration_team_points.csv`, `driver_effects.csv`(선수·차량 효과, 연결 그룹), `report.md`. 난수 시드가 고정되어 있어 다시 실행해도 같은 숫자가 나옵니다.
